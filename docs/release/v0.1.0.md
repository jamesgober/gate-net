# gate-net v0.1.0 - Scaffold

**The repository and the plan.** v0.1.0 sets up the crate in the portfolio template and writes down the design before any code. There is no functional code in this release.

## What is gate-net?

<strong>gate-net</strong> answers one question: who is this? Credentials go in (a password, an API key, a session token, a one-time code), and an authenticated identity or a refusal comes out. It owns password hashing, API keys, session issue, rotation, expiry, and revocation, multi-factor checks, and the login throttling that makes credential stuffing expensive.

## What's in 0.1.0

- The crate manifest: edition 2024, MSRV 1.85, no dependencies, `Apache-2.0 OR MIT`.
- CI on Linux, macOS, and Windows, on stable and 1.85, plus `cargo audit` and `cargo deny`.
